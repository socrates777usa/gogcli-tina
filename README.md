# gogcli-tina

`gogcli-tina` is a personal, single-user desktop OAuth client. It lets the account owner's self-hosted assistant ("Tina"), which runs on the owner's own home server, work with the owner's own Google account: reading and sending the owner's email, managing the owner's calendar events, and working with the owner's own Drive, Docs, Sheets and Slides files.

It is not a public service, it has no other users, and it is not offered or distributed to anyone else.
